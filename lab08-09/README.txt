Задание 3. Алгоритм с несколькими условиями
Магазин предоставляет скидку в зависимости от исходной суммы покупки C:
•	если C < 1000 руб., скидки нет;
•	если 1000 ≤ C < 5000 руб., скидка составляет 5%;
•	если C ≥ 5000 руб., скидка составляет 10%.
Исходная сумма C ≥ 0. Требуется определить процент скидки r, сумму скидки D = C · r / 100 и сумму к оплате K = C − D. Итоговые денежные результаты округлить до двух знаков после запятой, сохраняя точность промежуточных расчётов.
Таблица величин
Обозначение	Смысл	Входная / промежуточная / выходная	Допустимые значения	Единицы
C	Исходная сумма покупки	Входная	C ≥ 0	руб.
r	Процент скидки	Промежуточная	0, 5 или 10	%
D	Сумма скидки	Выходная	D ≥ 0	руб.
K	Сумма к оплате	Выходная	K ≥ 0	руб.

1	C = 0	Нижняя граница, скидки нет	r = 0; D = 0,00; K = 0,00	r = 0; D = 0,00; K = 0,00	Совпадает
2	C = 999	Граница перед 1000, скидки нет	r = 0; D = 0,00; K = 999,00	r = 0; D = 0,00; K = 999,00	Совпадает

4	C = 4999	Граница перед 5000, скидка 5%	r = 5; D = 249,95; K = 4749,05	r = 5; D = 249,95; K = 4749,05	Совпадает
5	C = 5000	Граница 5000, скидка 10%	r = 10; D = 500,00; K = 4500,00	r = 10; D = 500,00; K = 4500,00	Совпадает
6	C = 6000	Больше 5000, скидка 10%	r = 10; D = 600,00; K = 5400,00	r = 10; D = 600,00; K = 5400,00	Совпадает
Проверка каждого условия
При C = 0: 0 < 1000? - истина ⇒ «Да» ⇒ r = 0. D = 0 · 0 / 100 = 0,00. K = 0 − 0 = 0,00.
При C = 999: 999 < 1000? - истина ⇒ «Да» ⇒ r = 0. D = 999 · 0 / 100 = 0,00. K = 999 − 0 = 999,00.
При C = 1000: 1000 < 1000? - ложь ⇒ «Нет» ⇒ переход ко второй проверке. 1000 < 5000? - истина ⇒ «Да» ⇒ r = 5. D = 1000 · 5 / 100 = 50,00. K = 1000 − 50 = 950,00.
При C = 4999: 4999 < 1000? - ложь ⇒ «Нет» ⇒ вторая проверка. 4999 < 5000? - истина ⇒ «Да» ⇒ r = 5. D = 4999 · 5 / 100 = 249,95. K = 4999 − 249,95 = 4749,05.
При C = 5000: 5000 < 1000? - ложь ⇒ «Нет» ⇒ вторая проверка. 5000 < 5000? - ложь ⇒ «Нет» ⇒ r = 10. D = 5000 · 10 / 100 = 500,00. K = 5000 − 500 = 4500,00.
При C = 6000: 6000 < 1000? - ложь ⇒ «Нет» ⇒ вторая проверка. 6000 < 5000? - ложь ⇒ «Нет» ⇒ r = 10. D = 6000 · 10 / 100 = 600,00. K = 6000 − 600 = 5400,00.
Почему условия охватывают все допустимые C: проверки идут последовательно и взаимоисключающе; при любом C ≥ 0 выполняется ровно одна из ветвей (C < 1000, иначе C < 5000, иначе C ≥ 5000), поэтому назначается ровно один процент скидки.
Задание 4. Алгоритм с циклом
Составить блок-схему вычисления суммы квадратов целых чисел от 1 до N включительно:
S = 1² + 2² + … + N².
N — целое, N ≥ 0. При N = 0 сумма равна 0.
Таблица величин
Обозначение	Смысл	Входная / промежуточная / выходная	Допустимые значения	Единицы
N	Верхняя граница	Входная	Целое, N ≥ 0	Безразмерная
i	Счётчик цикла	Промежуточная	Целое, 1 ≤ i ≤ N + 1	Безразмерная
S	Сумма квадратов	Выходная	Целое, S ≥ 0	Безразмерная

Ответы на контрольные вопросы:
1.	С чего начинается разработка блок-схемы по условию?
Ответ: с анализа условия задачи - определить, что требуется получить, выделить входные и выходные величины, их смысл, единицы и ограничения, записать формулы.
2.	Зачем указывать ограничения и единицы измерения?
Ответ: ограничения задают допустимые значения, единицы - физический смысл величин и правильную интерпретацию результата.
3.	Когда достаточно линейного алгоритма?
Ответ: когда все действия выполняются последовательно, один раз, без ветвлений и циклов.
4.	Как выбрать условие для определения большего числа?
Ответ: сравнить a и b: если a > b - больше a, иначе - b; при равенстве выводится общее значение.
5.	Почему важно проверять значения ровно на границе диапазона?
Ответ: границы - места возможных ошибок: важно убедиться, что значение попадает в правильную ветвь и нет «дырок» или пересечений.
6.	Как объединяются ветви перед общими действиями?
Ответ: стрелки всех ветвей сводятся в одну точку перед общим блоком (вывода или следующего действия).
7.	Какие начальные значения нужны счётчику и накопителю?
Ответ: накопителю - 0; счётчику - первое значение диапазона (например, 1).
8.	Как проверить правильность количества повторений?
Ответ: выполнить трассировку, посчитать число проходов тела цикла и сравнить с ожидаемым (для суммы от 1 до N - N проходов); проверить N = 0, N = 1, N = 4.
9.	Чем ожидаемый результат отличается от результата трассировки?
Ответ: ожидаемый вычисляется независимо (по формуле/смыслу), трассировка - пошаговым выполнением схемы; их совпадение подтверждает правильность.
10.	Какие материалы этой работы можно использовать при последующем написании программы?
Ответ: таблицы величин с ограничениями и единицами, блок-схемы как план логики, тестовые данные с ожидаемыми результатами.
