1.	Запустите пример проверки размера. Проверьте последовательности «12», «abc → 0 → 31 → 12». Объясните число проходов.
Код программы: 
namespace _14_15РПМ
{
    internal class Program
    {
        static void Main(string[] args)
        {
            int size;
            bool valid;
            do
            {
                Console.WriteLine("Количество участников (1-30):");
                string input = Console.ReadLine();
                if (input == null)
                {
                    Console.WriteLine("Ввод завершён");
                    return;
                }
                valid = int.TryParse(input, out size)
                        && size >= 1 && size <= 30;
                if (!valid)
                    Console.WriteLine("Нужно целое число от 1 до 30.");
            }
            while (!valid);
            Console.WriteLine($"Принято: {size}");
        }
    }
}

2.	Реализуйте арифметический подсчёт количества цифр через do…while для 0, 7, 1000; ожидается 1, 1, 4.
Код программы: 
namespace _14_15РПМ
{
    internal class Program
    {
        static void Main(string[] args)
        {
            foreach (int value in new[] { 0, 7, 1000 })
            {
                int n = value;
                int count = 0;
                do
                {
                    n /= 10;
                    count++;
                }
                while (n > 0);
                Console.WriteLine($"{value} -> {count}");
            }
        }
    }
}

{

А. Через do…while запрашивайте int N от 0 до 20, затем выведите «Принято N». Нечисловой ввод также должен повторяться.
Код программы: 
namespace _14_15РПМ
{
    internal class Program
    {
        static void Main(string[] args)
        {
            int n;
            bool valid;
            do
            {
                Console.WriteLine("Введите целое число от 0 до 20:");
                string input = Console.ReadLine();
                if (input == null)
                {
                    Console.WriteLine("Ввод завершён");
                    return;
                }
                valid = int.TryParse(input, out n)
                        && n >= 0 && n <= 20;
                if (!valid)
                    Console.WriteLine("Ошибка: нужно целое число от 0 до 20.");
            }
            while (!valid);
            Console.WriteLine($"Принято {n}");
        }
    }
}

Б. Возраст для учебной анкеты — целое от 0 до 120. Организуйте получение корректного возраста.
Код программы: 
namespace _14_15РПМ
{
    internal class Program
    {
        static void Main(string[] args)
        {
            int age;
            bool valid;
            do
            {
                Console.WriteLine("Возраст для анкеты (целое от 0 до 120): ");
                string input = Console.ReadLine();
                if (input == null)
                {
                    Console.WriteLine("Ввод завершён");
                    return;
                }
                valid = int.TryParse(input, out age)
                        && age >= 0 && age <= 120;
                if (!valid)
                    Console.WriteLine("Некорректный возраст. Нужно целое от 0 до 120.");
            }
            while (!valid);
            Console.WriteLine($"Возраст принят: {age}");
        }
    }
}

Ответы на контрольные вопросы:
1.	Почему тело do...while выполняется хотя бы один раз?
Ответ: потому что проверка условия расположена после тела цикла. Сначала выполняется действие, и только потом проверяется необходимость повтора. Даже если условие изначально ложно, первый проход уже состоится.
2.	Что означает true в постусловии?
Ответ: это команда «продолжать цикл» (выполнить тело еще раз). В do...while условие является условием продолжения, а не выхода. 
3.	Зачем нужна точка с запятой после while?
Ответ: это требование синтаксиса C#. Конструкция do...while является единым оператором, который, как и любой другой, должен завершаться точкой с запятой, иначе компилятор выдаст ошибку.
4.	Почему переменную условия объявляют перед do?
Ответ: потому что переменная, объявленная внутри фигурных скобок do { ... }, видна только внутри них. Чтобы она была доступна в условии while (...), ее нужно объявить заранее, до начала цикла.
5.	Как TryParse помогает повторно запрашивать ввод?
Ответ: TryParse возвращает true или false, записывая число в out-параметр. Если текст неверный, возвращается false, условие продолжения срабатывает, и цикл запрашивает ввод снова, при этом программа не падает с ошибкой.
6.	Почему для цифр числа 0 подходит do...while?
Ответ: ноль имеет одну десятичную цифру, которую нужно обработать. В do...while тело выполнится хотя бы раз: для 0 цикл сработает один раз и завершится с результатом 1. Если бы использовался while (n > 0), тело не выполнилось бы вообще.
7.	Как ограничить число попыток?
Ответ: нужно завести переменную-счётчик попыток, увеличивать её на 1 внутри тела цикла и в условии продолжения проверять сразу два условия: и то, что правильный ответ ещё не введён, и то, что число попыток меньше заданного лимита.
8.	В каких задачах этот цикл менее удобен, чем for?
Ответ: когда число повторений известно заранее или первый проход не обязателен. Например, для вывода чисел от 1 до n при n = 0 цикл do...while сделает лишний проход, а for корректно не выполнится ни разу.
